⚖️ Authorization Required

BugCopilot only performs recon on targets you are explicitly authorized to test. You must confirm that you have written permission from the program owner (via a public bug bounty platform, a private program invite, or explicit written permission) before any scanning begins. All actions are logged locally. Unauthorized testing is illegal and unethical.
